##### WTI Crude Oil Model Comparison



###### Objective

The goal of this project was to predict WTI crude oil prices one month ahead using a persistence baseline model and a linear regression model.



###### Data and Results

I used current oil prices, oil prices from the previous two months, and the manufacturing index as predictors for linear regression. The data were divided into training and testing sets to evaluate both models. The results showed that linear regression had lower prediction errors and performed better overall compared to the baseline model.



###### Conclusion

The linear regression model was more accurate at predicting future oil prices. Using previous oil prices and the manufacturing index helped improve predictions compared to simply using the current oil price. However, both models still had difficulty predicting sudden changes in oil prices.
